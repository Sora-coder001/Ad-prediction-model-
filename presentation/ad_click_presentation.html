01 · Preprocessing

Preprocessing Steps

  • Dropped rows with a missing target (clicked) before any modeling.
  • -1 sentinel handling: for tenure, cookie age, session time, and device-user count columns, added an _na flag then converted -1 to NaN — preserving "unavailable" as its own signal.
  • One-hot encoded 5 categorical columns (ad format, audience segment, placement, traffic channel, device platform), fit jointly across train and test so columns always match.
  • Built a median-imputed + standardized version of the features specifically for the linear model.
  • Added 3 engineered interaction features: publisher tenure ratio, session intensity (elapsed time × device users), and cookie/session ratio.

04 · Final Model

Final Model

Blend: LightGBM + Ridge Logistic Regression

Optimized weights on the full 7-model set gave LightGBM ≈ 0.79, logistic regression ≈ 0.18, Extra Trees ≈ 0.02, and zero weight to Random Forest, XGBoost, HGB, and CatBoost.

Weighted ensemble OOF AUC: 0.7988, versus 0.7972 for LightGBM alone.

The near-zero-weight models were dropped, leaving a simple two-model blend that keeps essentially all of the ensemble's benefit.

05 · Why This Model

Why This Model Was Selected

  • LightGBM had the highest solo OOF AUC of every model tried.
  • XGBoost, HGB, and CatBoost are all gradient-boosted trees trained on the same features — their predictions were highly correlated with LightGBM's, so the optimizer assigned them zero weight: they were redundant, not just weaker.
  • Logistic regression scored lower alone, but it models the data linearly rather than through trees, so its errors are genuinely different — it earned real weight in the blend.
  • Random Forest and Extra Trees added negligible value once boosting and a linear model were present.
  • Net result: a 2-model blend that is simpler and faster than the full 7-model ensemble, at effectively the same AUC.
06 · Lessons

Key Lessons & Insights

  • Gradient boosting dominates on this kind of imbalanced, mixed-type tabular data.
  • Ensembling only helps with diversity. Blending near-identical models (LightGBM, XGBoost, CatBoost) added nothing — model family diversity mattered more than model count.
  • A weaker model can still be valuable in a blend if it makes different mistakes — logistic regression proved this despite its lower solo score.
  • Sentinel values carry information. Flagging -1 as "unavailable" before imputing preserved a real signal rather than treating it as a literal small number.
  • Simplicity paid off. A 2-model blend matched a 7-model ensemble almost exactly — added complexity did not translate into added performance.
